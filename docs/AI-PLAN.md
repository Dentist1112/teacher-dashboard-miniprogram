# AI 识别 · 方案设计与 MVP 计划（拍照录成绩）

> **落地状态（2026-09-05）：MVP 已上线，密钥可「在 App 内粘贴」。**
> - 云函数 `ocrScore` 已部署：取图→视觉大模型→结构化成绩，含鉴权/限流(10次/分)/重试/信封。
> - grades 页已接入「📷 拍照录」按钮 + 「📋 粘贴名单文本」兜底（无需密钥即可用）。
> - **密钥配置有两种，任一即可**：
>   1) 小程序「设置 → AI 识别密钥」粘贴（**推荐**，不用碰控制台，只存本人云库 aiConfig，不外传）——本次新增；
>   2) 云函数 `ocrScore` 环境变量填 `AI_KEY`（可选 `AI_BASE_URL`/`AI_MODEL`，默认混元视觉，OpenAI 兼容协议）。
> - **没填密钥时**：拍照识别返回 `code 5001` → 前端自动转「粘贴文本」手动录入，功能不中断。
> - **填了密钥后**：自动识别 → 结果填回成绩输入框（带 AI 标记，低置信标黄）→ 老师核对 → 点「保存」落库。


## 一、选型建议（结论先行）

**推荐方案 A：大模型视觉直出结构化 JSON**（首选）

| 维度 | A. 大模型视觉（推荐） | B. 腾讯云 OCR | C. 手动粘贴（无密钥备选） |
|---|---|---|---|
| 输入 | 试卷/成绩单照片 | 同左 | 手机拍照后手动复制文字 |
| 识别目标 | 姓名+分数一次到位，**直接输出 JSON** | 只出纯文本，姓名/分数要自己再解析 | 人工粘贴文本 |
| 调用链路 | 小程序→云函数→大模型 API→返回 JSON | 小程序→云函数→OCR API→文本→再解析 | 小程序→云函数→大模型→JSON |
| 免费额度 | 各家有（如混元/DeepSeek 等活动额度） | **1000 次/月长期免费** | 同 A |
| 成本（超额） | ~0.01-0.1 元/次 | 通用 OCR ~0.015 元/次 | 同 A |
| 响应耗时 | 3-8 秒 | 1-2 秒 | 3-8 秒 |
| 手写体 | 较好 | 一般 | 看粘贴的是啥 |
| 失败兜底 | 重试1次→转人工确认 | 转方案A或人工 | 人工改 |

**推荐组合**：A 为主（一张照片直接出「姓名-分数」表），B 做兜底（A 挂了/格式怪时退 OCR+解析）。C 保留给没密钥时用。
你的量级（一次考试 30 人 × 每月几次）**远在任何一家的免费额度内，实际成本 = 0 元**。

## 二、调用链路（方案 A）

```
手机拍照/选图
  → wx.cloud.uploadFile 传云存储（拿到 fileID）
  → wx.cloud.callFunction('ocrScore', { fileID, subject, examName })
      云函数内：
      ① getWXContext 取 OPENID（鉴权：只允许本人处理自己的上传）
      ② 云存储 downloadFile 取图片 → base64
      ③ 调大模型视觉接口（密钥存云函数环境变量，绝不下发前端）
      ④ 解析模型返回 → 统一信封 { code, data: [{name, score, conf}] }
      ⑤ 限流：同一 OPENID 10次/分钟（云数据库记数），防刷
  → 小程序展示识别结果表格（每行可改）
  → 老师核对无误后 → api.batchAdd('grades', [...]) 入库
```

**安全要点**：密钥只放云函数环境变量；所有识别结果只是「建议值」，**必须老师确认才落库**（AI 抄错分数是重大事故，宁慢勿错）；限流防刷爆免费额度。

## 三、失败兜底策略

1. 模型超时（>15s）→ 前端提示重试（同一 fileID 不重复上传）；
2. 返回格式异常 → 云函数内重试 1 次（温度调低）；
3. 二次失败 → 返回 code 5000 + 引导用户走「手动录入」入口；
4. 识别出但置信度低的行 → 前端标黄提示「请核对」；
5. 姓名对不上名单（错别字）→ 前端做模糊匹配建议（编辑距离 ≤1 自动建议）。

## 五、你需要做的（拿密钥 + 粘进设置页）

**1) 拿一把视觉大模型的 API Key（OpenAI 兼容协议）**

- 方案①（默认，推荐）：腾讯云「混元大模型」API Key（支持图片输入，hunyuan-vision）
  1. 微信扫码登录 https://cloud.tencent.com ，顶部搜索「混元」
  2. 进入产品页，开通服务后点左侧「API Key 管理」
  3. 新建 API Key，复制那串字符（形如 `xxxxxxxx`，不是 SecretId/SecretKey 那对）
- 方案②：其它 OpenAI 兼容的**视觉**模型（如智谱 GLM-4V 等），拿到 key 后在设置页同时填「接口地址 + 模型名」。
  ⚠️ DeepSeek 的标准对话模型不支持图片输入，不适合本场景，别选。

**2) 把 Key 粘进小程序（不用碰控制台，不用发我）**
小程序 →「设置」→「AI 识别密钥」→ 粘贴保存。密钥只存你自己的云数据库（aiConfig），按 OPENID 隔离，不外传、不进代码。

> 若不想在 App 里存，也可在云函数 `ocrScore` 环境变量填 `AI_KEY`（会优先生效），填完重部署即可。
