# 发版后手动清单（每次发版后 3 分钟）

> 2026-09-05 v1.3.1 起。CLI 能自动做的都已自动化（tools/ship.sh 8 步门禁），
> 下面 3 步只能在网页/控制台做，CLI 没有接口。

## ① 设为体验版（每次发版都要）
1. 打开 https://mp.weixin.qq.com → 扫码登录
2. 左侧「管理」→「版本管理」
3. 「开发版本」里找到刚上传的 v1.3.1 → 点「设为体验版」
4. 手机上微信扫码即可真机体验

## ② ocrScore 超时改 20 秒（只做一次，配 AI 密钥前必须）
1. 微信开发者工具 → 左上角「云开发」按钮
2. 「云函数」→ 点 `ocrScore` → 右上角「配置」（或「版本与配置」）
3. 「超时时间」3 秒 → 改成 **20 秒** → 保存
- 为什么：视觉模型识别一张照片要 5~15 秒，默认 3 秒必超时（老师看到的就是「识别失败」）
- 为什么 CLI 改不了：2026-09-05 实测 `cli cloud functions deploy` 不应用 config.json 的 timeout
- 验证：改完后 `cli cloud functions info --names ocrScore` 应显示 timeout=20

## ③ 配 AI 密钥 + 真拍验证（想用拍照识别时做）
1. 拿密钥：腾讯云混元（https://cloud.tencent.com 搜「混元」→ API Key 管理 → 新建）
2. 小程序「设置 → AI 识别密钥」粘贴保存（存你自己云库，不外传）
3. 真拍验证：花名册页 → 拍照导入 → 拍一张真实名单 → 核对识别出的姓名
   - 识别错字正常，确认表可逐行改
   - 全部识别失败 → 先检查 ② 的超时改没改

## 验证工具（随时可跑）
```bash
node tools/e2e-slice.js 21     # 含 ocrScore 活性探针（5001=兜底正常）
node tools/audit-data.js       # 数据卫生
bash tools/ship.sh <版本> "<说明>"   # 完整 8 步门禁 + 上传
```
